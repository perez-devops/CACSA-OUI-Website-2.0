# Design Critic Mode

Never declare a UI finished immediately after implementation.

Switch into DESIGN CRITIC MODE.

Review the work as:

- Creative Director
- Senior Product Designer
- UX Researcher
- Brand Strategist
- Senior Frontend Engineer
- Accessibility reviewer

## Critique categories

Inspect for:

1. Generic AI patterns
2. Excessive content
3. Weak hierarchy
4. Poor typography
5. Weak font pairing
6. Weak color hierarchy
7. Excessive colors
8. Excessive cards
9. Excessive rounded corners
10. Excessive shadows
11. Excessive gradients
12. Poor whitespace
13. Repetitive layouts
14. Weak CTA hierarchy
15. Unnecessary sections
16. Unnecessary animations
17. Poor mobile composition
18. Accessibility issues
19. Inconsistent spacing
20. Inconsistent components
21. Weak brand personality
22. Visual noise
23. Poor content prioritization
24. Performance problems

## Critique process

For every significant problem:

IDENTIFY
→ EXPLAIN WHY
→ PROPOSE A BETTER SOLUTION
→ IMPLEMENT THE IMPROVEMENT

Do not defend weak design decisions merely because they were already implemented.

If removing something improves the design, remove it.

If simplifying something improves clarity, simplify it.

## The removal test

Ask for every major element:

"If I remove this, does the experience become worse?"

If no:

REMOVE IT.

Apply this to:
- sections
- buttons
- icons
- text
- animations
- borders
- shadows
- decorative elements
- statistics
- cards

## The why test

Every major decision must have an explanation.

Why this font?
Why this color?
Why this amount of whitespace?
Why this layout?
Why this animation?
Why this CTA?
Why this section?

If there is no meaningful reason, reconsider it.

## Professional review

### Typography
- Is hierarchy immediately understandable?
- Are font choices appropriate?
- Are weights intentional?
- Is line length readable?
- Are heading wraps controlled?

### Color
- Is the palette coherent?
- Is contrast accessible?
- Is the accent color overused?
- Does color reinforce the brand?

### Layout
- Is alignment intentional?
- Is spacing consistent?
- Is there sufficient breathing room?
- Does the page have rhythm?

### Content
- Is every section necessary?
- Is information prioritized?
- Is there filler?
- Is copy concise and specific?

### Motion
- Does animation communicate?
- Is anything distracting?
- Is motion performant?
- Does reduced motion work?

### Brand
- Does the product have personality?
- Could this design belong to any company?
- What makes it memorable?

### UX
- Can a first-time user understand the product?
- Is the primary action obvious?
- Are loading, empty, error and success states handled?

### Responsive
- Does the composition remain strong on mobile?
- Has the layout been recomposed rather than merely compressed?

### Accessibility
- Can keyboard users navigate?
- Is focus visible?
- Is contrast adequate?
- Are interactive controls understandable?

## Final refinement loop

After critique:

1. Fix the highest-impact issues.
2. Re-evaluate the entire page.
3. Remove unnecessary visual noise.
4. Check consistency across pages.
5. Check mobile and desktop.
6. Check performance.
7. Repeat until additional changes would provide little meaningful improvement.

Do not optimize for the number of design elements.

Optimize for clarity, experience, coherence and impact.

## Final quality bar

The result should feel:

- intentional
- coherent
- distinctive
- clear
- calm
- responsive
- memorable
- elegant

It should not feel like an AI assembled a template.
